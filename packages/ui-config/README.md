# @dinary/ui-config

This library was generated with [Nx](https://nx.dev).

## Features

- **Environment Settings:** Provides environment settings and configurations to be shared across various Angular applications within the Dinary ecosystem.

## Getting Started

The `@dinary/ui-config` library is generated with [Nx](https://nx.dev) and is intended to be used within the Dinary ecosystem. Before installing, make sure you have a Dinary workspace set up and that all necessary dependencies are in place.

## Publishing

After building your library with `yarn nx build ui-config`, go to the dist folder `dist/packages/ui-config` and run `npm publish`.

## Installation

To install the `@dinary/ui-config` library, run the following command in your Angular project:

```bash

# or
```
